# PBA — Power Backup Analytic · Documentation (English)

> Versi Bahasa Indonesia: [../id/00-INDEX.md](../id/00-INDEX.md)

PBA is the decision-support dashboard for Telkomsel **AREA1** power backup (ENOM, managed by Triple-E). It answers two management questions:

1. **MBP (Mobile Backup Power)** — when PLN fails, which sites need an MBP, which MBP should go, and can it arrive before the battery runs out? How many MBPs do we need, and where?
2. **BBS (Battery Backup System)** — which batteries are dead, critical or degraded, what should be done (replace, upgrade, test, verify), and in which order?

Every number in PBA is computed **per site first** and then rolled up to cluster (TO), NOP and AREA, so any figure on a map, KPI or chart can be traced back to the individual sites and their evidence.
